# Персональное приглашение

Статическое Telegram Mini App на Vue 3 + Vite. Графитовая обложка раскрывается во внутреннюю открытку цвета бумаги. Третий экран подтверждает принятие локально. Без сервера, базы, аналитики и хранения персональных данных.

## Локальный запуск

Требуется Node.js 22.12+ (или 24) и npm.

```bash
npm install
npm run dev
```

## Тексты

Все тексты, дата, время и место находятся в `src/content.js`. Значения `[Дата]`, `[Время]`, `[Место]` замените перед отправкой. Дизайн — `src/style.css`. Состояние ответа живёт только в памяти: обновление страницы вернёт обложку. Реального уведомления организатора нет.

## GitHub Pages

1. Создайте репозиторий GitHub и загрузите **содержимое этой папки** в корень ветки `main`, включая скрытую папку `.github`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Откройте **Actions → Deploy to GitHub Pages → Run workflow** или отправьте новый коммит в `main`.
4. Дождитесь успешного workflow. Адрес будет показан в deployment: `https://USERNAME.github.io/REPOSITORY/`.

В `vite.config.js` задан `base: './'`: ресурсы работают и в подпапке репозитория. Клиентского роутера нет, дополнительный 404.html не требуется.

Локальная production-проверка:

```bash
npm run build
npm run preview
```

## Подключение к Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather), командой `/newbot`, если его ещё нет.
2. После публикации задайте для бота Menu Button через `/setmenubutton`: название, например «Приглашение», и HTTPS-адрес GitHub Pages.
3. Откройте чат с ботом и нажмите кнопку меню. При необходимости настройте Main Mini App через BotFather, чтобы использовать кнопку запуска в профиле бота.

Токен бота в проект добавлять не нужно. Telegram Web App SDK подключён в `index.html`: ready, expand, цвета заголовка/фона, тактильный отклик и кнопка «Назад». В обычном браузере приложение тоже работает. Интерфейс использует собственную нейтральную тему, safe areas и prefers-reduced-motion; низкие экраны могут прокручиваться.

SDK загружается с telegram.org. Основной интерфейс не зависит от его наличия; если SDK недоступен, Telegram-специфические функции отключены.

## Что проверить перед отправкой

Замените заглушки, откройте ссылку внутри Telegram на iPhone и Android, пройдите обложку → приглашение → подтверждение → назад. Также проверьте большой системный шрифт и уменьшенную анимацию. После первого `npm install` сохраните созданный `package-lock.json` в репозитории; затем можно использовать `npm ci` для воспроизводимых установок.

Сборка проекта сама по себе не подтверждает работу во всех мобильных WebView.
